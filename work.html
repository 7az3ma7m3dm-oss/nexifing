The brief

Build an Egypt-based Fortnite top-up store that could handle real orders end-to-end — V-Bucks, Crew subscriptions, and gifts — with a payment verification flow, an admin console for the owner, and real-time order tracking for customers. No third-party storefront platforms, no shortcuts.

What we built

  • Full customer-facing storefront with product catalog, cart, favorites and search
  • Checkout with 3 payment gateways (Vodafone Cash, InstaPay, Telda)
  • Payment proof upload with image storage
  • Order tracking system — customers enter their code, see live status
  • Promo code engine with usage limits and expiry
  • Customer reviews with verified-purchase badges
  • Owner admin console with role-based access (owner / admin / staff)
  • Payment approval workflow: pending → paid → processing → delivered
  • Real-time activity log with every action tracked
  • Deals, bundles and best-sellers automation
  • Support ticket system with staff notifications
  • Firebase backend with strict security rules
